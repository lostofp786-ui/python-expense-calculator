# Python Expense Calculator

A beginner-friendly Python project to track expenses and calculate spending summaries.

## Features
- Accepts multiple expenses from the user
- Validates expense amounts and categories
- Calculates category-wise spending
- Displays total expenses
- Identifies the highest and lowest expenses
- Shows a spending message based on a ₹1,000 threshold

## Technologies Used
- Python
- Lists and tuples
- Dictionaries
- Loops and conditional statements
- Exception handling
- Lambda functions

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python python.py`
